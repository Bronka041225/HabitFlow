# HabitFlow (专注)

**HabitFlow** 是一款现代化的 Android 习惯追踪应用，采用 **Jetpack Compose** 和 **Material 3** 构建。它专为追求极简、高效和美观的用户设计，采用“深邃黑 + 电光橙”的暗黑风格，提供丝滑的交互体验和丰富的数据可视化功能。

![Android](https://img.shields.io/badge/Android-15.0-green.svg) ![Kotlin](https://img.shields.io/badge/Kotlin-1.9.24-blue.svg) ![Compose](https://img.shields.io/badge/Jetpack%20Compose-M3-orange.svg)

## 🌟 核心功能 (Features)

*   **习惯管理**:
    *   创建个性化习惯（自定义名称、每日目标、**主题色**）。
    *   支持 7 种高饱和度主题色（电光橙、海洋蓝、薄荷绿等）。
    *   长按卡片即可删除习惯。
*   **高效打卡**:
    *   首页卡片直观展示进度条。
    *   点击 `+` 号唤起快捷面板，支持 **+1, +5, +10** 或自定义数值输入。
*   **数据可视化 (Data Viz)**:
    *   **GitHub 风格热力图 (Heatmap)**: 以月为单位横向滚动，直观展示一整年的坚持情况（使用 Canvas 高性能绘制）。
    *   **趋势折线图 (Trend Chart)**: 基于 Vico 引擎，展示最近 30 天的打卡波动趋势。
*   **UI/UX**:
    *   **Pro Max 暗黑模式**: 纯黑底色 (`#121212`) 配合半透明玻璃拟态卡片。
    *   **无缝交互**: 解决了屏幕旋转白屏闪烁问题，全手势操作。

## 🏗️ 技术架构 (Tech Stack)

本项目严格遵循 Google 推荐的 **MVVM (Model-View-ViewModel)** 架构与 **Clean Architecture** 思想。

*   **UI Layer**: Jetpack Compose (Material 3), Navigation Compose.
*   **State Management**: ViewModel, Kotlin Coroutines (StateFlow, Flow).
*   **Data Layer**:
    *   **Room Database**: 本地持久化存储 (SQLite)。
    *   **Repository Pattern**: 隔离数据源与 UI 逻辑。
*   **Dependency Injection**: Manual DI (Factory pattern).
*   **Charts**: Vico (Compose version) + Canvas Custom Drawing.
*   **Build System**: Gradle Kotlin DSL (KTS), Version Catalog (`libs.versions.toml`).

## 🛠️ 关键技术难点突破

1.  **高性能热力图**: 为了保证在低端设备上左右滑动 12 个月的数据依然丝滑，我们放弃了传统的 `FlowRow` 布局嵌套，转而使用 Compose `Canvas` 直接在 GPU 层级进行绘制，性能提升显著。
2.  **沉浸式暗黑体验**: 通过修改 `themes.xml` 的 `windowBackground` 和 Status Bar 颜色，彻底解决了 Android App 启动和旋转时的“白屏闪烁”通病。
3.  **Vico 图表定制**: 深度定制了 Vico 图表的坐标轴 Formatter 和样式，使其在深色背景下清晰可见，并解决了日期旋转导致的布局截断问题。
